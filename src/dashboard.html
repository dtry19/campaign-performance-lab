Reporting quality & definitions

CTR = clicks / impressions. Post-click credited CVR = unique credited conversion keys with an observed clicked credited impression / clicks. CPA = transformed cost / all unique credited conversion keys, including those without an observed click. These denominators intentionally differ. Undefined ratios display as —.

Each credited conversion key (ID + conversion timestamp) is counted once globally. Some source IDs recur at different timestamps, so ID alone is insufficient. For cohort reporting we assign it to the latest observed clicked credited impression, otherwise the latest observed credited impression. This project rule is not proof of the platform's exact credited touchpoint. Filtering days selects allocated impression cohorts with observed follow-up outcomes. Source impressions are retained: there is no impression ID that would justify automatic deduplication.

No raw user or conversion identifiers are published. No region, channel, calendar date, dollar cost, revenue or performance result has been invented.
